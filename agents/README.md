# Wisp Agent Playbooks & Runtime Prompt Library

This directory houses two categories of agent artifacts:

1. **`playbooks/`**: Specialized role definitions for autonomous development agents working on Wisp's frontend, backend, and content pipeline.
2. **`prompts/`**: Versioned system prompt specifications used by `backend/src/modules/ai-gateway/prompts/prompt-builder.ts` to shape grounded, spoiler-safe television cards.
