# Branch Guide: `docs` (Documentation, Hackathon Deliverables & Agent Playbooks Workstream)

## 1. Branch Goal
The **`docs`** branch is dedicated to maintaining Wisp's **Project Proposal**, **System Architecture**, **API Specifications**, **Fire TV 10-Foot UX Guide**, **Modular AI Engine Guide**, **Developer Friction Log (for the 10% judging bonus)**, **Product & SDK Feedback**, and **AI Agent Playbooks**.

## 2. Primary Ownership Scope
- **`docs/PROPOSAL.md`** — Refined hackathon project proposal and positioning.
- **`docs/ARCHITECTURE.md` & `docs/API_SPEC.md`** — Mermaid sequence diagrams, layer contracts, and REST/programmatic API docs.
- **`docs/AI_ENGINE_GUIDE.md` & `docs/FIRE_TV_UX_GUIDE.md`** — Developer guides for `@wisp/ai-engine` and 10-foot Fire TV UI.
- **`docs/FRICTION_LOG.md`** — Real-time log of SDK/tooling quirks, workarounds, and recommendations (qualifies for up to **10% Hackathon Bonus**).
- **`docs/PRODUCT_FEEDBACK.md` & `docs/HACKATHON_READINESS.md`** — Official hackathon submission deliverables and sub-3-minute demo script.
- **`agents/` & `AGENTS.md`** — Playbooks and prompt specifications.
